# Active State and Operation Feedback Design

## Goal

让用户在切换供应商时能确认三件事：操作是否成功、当前真正生效的是哪个方案、以及有一个回到官方 Claude 的现成入口。

## Scope

本次功能包含：

- 首次启动时预置一个名为「官方 Claude」的普通方案。
- 切换时跳过值为空字符串的环境变量，不写入 Claude 配置。
- 侧边栏标出当前生效的方案，以及生效配置不属于任何已存方案的情况。
- 保存与切换成功后，按钮就地反馈，并在右上角显示一条自动消失的消息。

本次功能不包含：

- 把「官方 Claude」做成不可编辑或不可删除的特殊条目。
- 表单中未保存的编辑参与生效判定。
- 修改 `switch_env` 的备份、原子写入与回读校验逻辑。
- 修改保存到 `providers.json` 的数据形状。

## Native Provider

「官方 Claude」是一个普通方案，没有任何特殊标记：可编辑、可重命名、可删除，切换走与其他方案完全相同的代码路径。

预置只发生在方案列表为空时——包括首次启动，以及用户删空了所有方案后的下一次启动。它的供应商字段（API 地址、API Key、主模型、四个模型映射、Subagent 模型）全部留空，行为偏好沿用 `defaultProviderEnv` 中的现有默认值。

应用不保证这个方案始终存在。用户删除后不会被重新塞回，除非方案列表变空触发了预置条件。

## Empty Value Filtering

`switch_env` 在写入 Claude 配置前，滤掉值为空字符串的键。这条规则对所有方案一致生效，不是「官方 Claude」的专属行为。

因此主模型留空的方案切换后，Claude 配置中不会出现空的模型名，与输入框「跟随主模型」的提示一致；「官方 Claude」的供应商字段则完全不出现在配置里。

`providers.json` 保存的仍是完整字段（空值以 `""` 存在），表单渲染不受影响。过滤只发生在写入 Claude 配置这一步。

## Active State Detection

前端新增一个后台命令读取当前生效的环境变量。已有的导入命令在配置文件缺失时返回错误；新命令在文件缺失或 JSON 损坏时返回明确的「读不到」结果，界面照常渲染，只是不显示生效状态。

`src/activeProvider.ts` 提供一个纯函数，输入当前生效的环境变量与全部已存方案，按顺序判定：

1. 方案经过空值过滤后与生效环境变量完全一致 → 该方案标记「已生效」。
2. 仅 API 地址与 API Key 一致、其余字段不同 → 该方案标记「已改动未生效」。
3. 以上都不匹配 → 侧边栏顶部提示当前生效的配置不属于任何已存方案。

比对前必须用与写入相同的空值过滤规则处理方案，否则留空字段的方案永远无法匹配它自己刚写出的配置。「官方 Claude」由第 1 条自然匹配，不需要单独分支。

判定在应用启动时、每次切换成功后、以及每次保存成功后各执行一次。保存后需要重新判定，因为方案内容变了而 Claude 配置没变，原本「已生效」的方案可能变成「已改动未生效」。

判定只读取已保存的方案数据，表单中未保存的编辑不参与。生效环境变量在启动时读取一次后缓存，切换成功后重新读取；保存操作不改动 Claude 配置，因此不重新读取。

## Operation Feedback

保存与切换成功时，按钮文案变为「✓ 已保存」或「✓ 已切换」并禁用 2 秒，同时右上角显示一条消息，2 秒后按钮与消息一并复原。

失败时按钮立即复原，右上角显示红色消息，不自动消失，带关闭按钮。同一时刻只存在一条消息，新消息顶掉旧消息。页面底部当前那条永不消失的提示条移除。

只有保存与切换提供按钮就地反馈。导入和同步主模型的结果直接呈现在表单上，仅显示右上角消息。删除方案同样只显示右上角消息。

## Architecture

- `src-tauri/src/claude_settings.rs`：`switch_env` 增加空值过滤；备份、原子写入、回读校验逻辑不变。
- `src-tauri/src/main.rs`：新增读取当前生效环境变量的命令；`list_providers` 在列表为空时预置「官方 Claude」。
- `src/activeProvider.ts`：生效判定纯函数，不依赖 Tauri API。
- `src/main.tsx`：接入生效状态显示与操作反馈。

## Acceptance Criteria

- 方案列表为空时启动，出现「官方 Claude」方案；该方案可编辑、可重命名、可删除。
- 切换到供应商字段留空的方案后，Claude 配置中不含这些键，其余键与非环境变量段原样保留，且生成了备份。
- 切换到某方案后，侧边栏该方案显示「已生效」。
- 修改已生效方案的主模型并保存但不切换，该方案显示「已改动未生效」。
- 手动编辑 Claude 配置使其不匹配任何方案后重启应用，侧边栏顶部出现相应提示。
- Claude 配置缺失时应用正常启动，方案列表可用，不显示生效状态。
- 保存与切换成功后按钮就地反馈并在 2 秒后复原；失败时消息为红色且不自动消失。
